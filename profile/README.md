# Li Research Group · University of Wisconsin–Madison

Software and analysis code from the lab of **Dr. Lingjun Li**, School of Pharmacy and Department of Chemistry, UW–Madison.

The group develops mass spectrometry methods for neuropeptidomics, quantitative proteomics and glycomics, mass spectrometry imaging, ion mobility-MS, and capillary electrophoresis-MS. This organization hosts the lab's open-source tools and the code and data behind its publications.

| [**MSI-Parser**](https://github.com/LingjunLiResearch/MSIparser) | Analysis of single-cell MS imaging data | [Nat. Commun.](https://www.nature.com/articles/s41467-023-40512-6) |
